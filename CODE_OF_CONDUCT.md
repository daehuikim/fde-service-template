# Code of Conduct · 행동 강령

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) ([한국어 번역](https://www.contributor-covenant.org/ko/version/2/1/code_of_conduct/)). It applies in issues, pull requests, discussions, reviews and any space where someone represents the project.

이 프로젝트는 [Contributor Covenant 2.1](https://www.contributor-covenant.org/ko/version/2/1/code_of_conduct/)을 따릅니다. 이슈, PR, 토론, 리뷰 등 프로젝트를 대표하는 모든 공간에 적용됩니다.

## In short · 요약

- Be respectful and assume good intent. Critique ideas, evidence and code, not people.
- No harassment, discrimination, personal attacks, sexualized content, or publishing someone's private information.
- Do not post customer data, secrets or another person's confidential material, even to make a point.
- 사람이 아니라 아이디어·근거·코드를 비판합니다. 괴롭힘, 차별, 인신공격, 타인의 개인정보·고객 데이터 공개를 금지합니다.

## Reporting · 신고

Report a concern privately to a maintainer listed in [GOVERNANCE.md](GOVERNANCE.md#maintainers), using the contact on their GitHub profile. Do not report conduct issues in a public thread. Maintainers will review every report, keep the reporter's identity confidential, and recuse themselves from a report that involves them.

[GOVERNANCE.md](GOVERNANCE.md#maintainers)의 메인테이너에게 GitHub 프로필의 연락처로 비공개 신고해 주세요. 신고자 신원은 보호되며, 신고 대상인 메인테이너는 처리에서 빠집니다.

## Enforcement · 조치

Maintainers follow the Contributor Covenant [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): correction, warning, temporary ban, then permanent ban, depending on severity. They may remove, edit or reject comments, commits, issues, showcase entries and other contributions that break this code.
