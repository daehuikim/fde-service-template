# EV 입지 검토 설계

결론: **지금 필요한 것은 투자 최적화 앱보다 자료 정합성과 조사 shortlist**다. 기존 공급 위치는 확보했지만 투자 수요/비용/전력/토지 자료는 없다. 파일/SQL+공간 조회로 현재의 빈칸을 드러내고, 검증된 수치 목표가 생기면 제약 조합 평가로 확장한다. ontology/ML/LLM을 필수로 하지 않는다.

[설계 원본](design.json)에는 5개 대안, 5개 요구사항, 8개 실패·변화 시나리오와 배포/운영 책임을 기록했다. 현재 선택은 조사 지원에 한정하며 `executionAllowed=false`다.

## 실제 확보 자료

공식 API의 California 공개/available 충전소 첫 8건을 [snapshot](data/public-stations.json)에 저장했다. 8건 모두 좌표가 있지만 90일을 넘은 확인일이 7건이다. 이는 가동 중/미가동 판정이 아니라 추가 확인 필요 신호다. [profile](data/profile.json). 편의 표본이므로 모집단 비율이나 특정 지역 투자 결론으로 일반화하지 않는다.

자료 사용 조건: [AFDC data download terms](https://afdc.energy.gov/data_download). 재사용/배포 관련 조건과 비보증/비후원/책임 조항을 확인한다. DOE/NLR/Alliance가 이 프로젝트를 후원·보증한다는 표현을 하지 않는다. 수집 API에는 공개 DEMO_KEY만 사용했고 개인 API key를 저장하지 않았다.

## 작은 수치 반례

[가상 계산표](data/decision-table.json)의 수요 proxy는 c=80,d=70,e=60,f=40이고 예산은 9다.

- hub: 비용6, c+d+e=210 → 개별 coverage/비용=35.
- south: 비용5, d+e=130 → 26.
- east: 비용4, c+f=120 → 30.

개별 비율 greedy는 hub를 먼저 택해 210에서 멈춘다. south+east는 비용9에 중복 없이 250을 덮는다. 이는 조합 결정을 단순 입지 점수 합으로 대신하면 안 된다는 **설계 반례**다. 현장 수익/이용률/사용자 절감 결과가 아니다. grid/허가 unknown인 cheap 후보는 높은 점수여도 승인하지 않는다. 비용 상한을 south=6, east=5로 바꾸면 같은 조합의 비용은 11로 예산9를 초과한다. nominal 최적안을 불확실한 예산에서도 안전하다고 표시하면 안 된다. 실제 구현/solver 성능 시험은 하지 않았다.

## 선택이 바뀌는 조건

1. 실제 비용 범위/수요/도달성/부지 적격성이 승인되고 조합 투자를 해야 한다 → MIP 등 제약 최적화를 비교한다.
2. 충분한 세션 이력과 시간분할 holdout이 확보된다 → 단순 통계 대비 예측 모델의 추가 이득을 검토한다.
3. 여러 팀이 같은 자산/행위/권한을 반복 공유한다 → SQL/API와 ontology의 재사용/운영비를 다시 비교한다.
4. 자료가 여전히 없다 → 추정값을 늘려 투자 결론을 만들지 않고 현장 자료 취득 계획을 인계한다.
