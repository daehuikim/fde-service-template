# 빠른 검토 초안 · partner-qa

공개 자료/가정 기반 초안 · 현장 검증/실행 승인 아님

**배경** 상품 파트너가 제출자료와 QA 절차를 찾느라 반복 문의합니다. 안내와 상품 승인 권한을 나눠야 합니다.

**페인포인트** 문서 버전·파트너 권한·담당자가 분산되면 같은 문의가 오가고, 만료/충돌한 안내가 전달될 수 있습니다.

**소구점 · 기대 이득(가설)** 유효한 근거와 다음 행동, 담당자 이관 맥락을 한 번에 보여주는 지원입니다. 해결률·절감 효과는 미검증입니다.

**기술 조합 · 선택 이유** FAQ baseline+권한 필터 검색+정책 규칙을 우선 비교합니다. 자유문 해석이 실제 병목이면 RAG 초안과 LLM provider를 평가하고 하네스로 실행을 제한합니다.

**확장 조건** 문서/언어/질의가 늘면 검색 방식을, 여러 팀의 관계 추적이 병목이면 공유 모델을 재검토합니다.

**취약점 · 반론** 실제 정책·문의가 없어 검색이 FAQ보다 나은지도 가설입니다. RAG를 써도 근거 오류·권한 누출·모르는 답의 생성 위험은 남습니다.

**다음 확인** 가명 문의20–30건과 정책 소유자 정답/이관 기준을 확보해 FAQ·검색·선택 LLM을 같은 조건으로 비교합니다.
