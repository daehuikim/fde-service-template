# 빠른 초안의 유용성 검토

평가: 동일 AI의 self review. 실제 사람의 읽기 시간/이해도/채택 의향은 not_run.

| 기준 | EV 초안 | 파트너 QA 초안 |
|---|---|---|
| 배경과 누구의 결정인지 바로 보이는가 | 조사/투자 후보 구분이 첫 문장에 있음 | 파트너 문서 안내와 승인 경계가 첫 문장에 있음 |
| 구체적인 pain과 기대 이득이 있는가 | 분산 자료/중복/오래된 정보와 재확인 수고를 연결 | 버전/권한/담당자 분산과 이관 수고를 연결 |
| 방법 선택 이유와 대안 전환이 있는가 | 지금 SQL/조사, 자료 검증 후 optimizer로 전환 | FAQ/검색 우선, 실제 비정형 병목일 때 LLM/provider 비교 |
| 확장성을 기능 나열 대신 조건으로 쓰는가 | 후보 조합/팀 재사용이 커질 때 재선택 | 문서/언어/관계 질의 증가에 따라 재선택 |
| 가장 강한 반론을 남기는가 | 8개 공급 위치로 투자안을 정당화할 수 없다고 명시 | 검색이 FAQ보다 나은지조차 현장 검증 전 가설이라고 명시 |
| 다음 행동이 구체적인가 | 후보/견적/계통 자료와 기획자 관찰 | 가명 문의20–30건과 정책 정답/이관 기준 |

본문 글자 수와 읽기 추정은 `pnpm brief ...`로 실제 생성한다. 500자/분 가정은 측정된 표준 속도가 아니다. 900자 상한/필수 취약점 항목/3개 이상 서로 다른 비판 관점은 자동 검사하되, 의미/진실/도움 정도는 그 검사로 증명되지 않는다.

장점: 상세 문서를 읽기 전에 현재 결정과 부족한 증거를 파악할 수 있는 초안을 제공한다. 한계: 기술 용어를 처음 보는 사람은 glossary를 추가로 읽어야 하며, 정량적 pain/baseline 수치가 없어 소구점은 가설에 머문다. 현장 담당자가 실제 1–2분 안에 핵심 선택과 다음 행동을 설명할 수 있는지 다음 파일럿에서 관찰한다.
