# 현장 문제 brief · synthetic demo

대상: 운영 요청 CSV를 검토하는 담당자. 현재 대안 가설: 스프레드시트의 필터·중복 표시·수동 확인. 실제 조직 관찰과 인터뷰는 아직 없다.

완료 작업: CSV 접수 → 행/필드 오류 확인 → 원본 정정 → 재검증 → 근거가 포함된 결과 내보내기. 재무 요청은 양수 금액, request_id는 batch 안에서 중복 불가, 부서는 3개 enum을 사용한다. 이 규칙은 합성 예제일 뿐 실제 고객 정책이 아니다.

개선 가설: 반복 검사 시간과 누락 오류를 줄인다. 전환 비용: CSV 열 이름 변경, 부서 enum 합의, 기존 승인·저장 시스템 연계, 접근 권한 검토. 성공 기준은 사용자 파일럿 전에 정하고 baseline과 같은 데이터로 측정한다. 검증 전 우월성을 주장하지 않는다.
