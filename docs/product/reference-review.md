# Open-source product/reference review

Reviewed 2026-11-02. Star counts are a snapshot from GitHub's repository API, not a quality score or a claim of feature parity.

| Official repository | Stars at review | Pattern adopted here |
|---|---:|---|
| [astral-sh/uv](https://github.com/astral-sh/uv) | 91,458 | A clear purpose, install command and runnable first task before detailed reference |
| [pydantic/pydantic-ai](https://github.com/pydantic/pydantic-ai) | 20,997 | Typed Python API, progressive documentation and a clear separation of core and optional capabilities |
| [langchain-ai/langgraph](https://github.com/langchain-ai/langgraph) | 44,334 | Explicit orchestration boundaries and durable artifacts rather than vague agent claims |
| [microsoft/markitdown](https://github.com/microsoft/markitdown) | 193,511 | CLI/library parity, small core and separately documented optional integrations |

Official READMEs were read through Firecrawl; repository metadata was checked with GitHub's API. Packaging follows the [PyPA packaging guide](https://packaging.python.org/en/latest/tutorials/packaging-projects/). No code, logos, screenshots, performance claims or brand assets were copied from these projects.

The product figures are original SVGs generated by scripts/brand-assets.mjs and rendered with resvg. Both PNGs were visually inspected. The design uses a dark ink/sea-green palette, a concrete decision record and a small host/core/delivery diagram instead of a directory inventory. These are architecture illustrations; the hero card is not a screenshot of a shipped web dashboard.

Implemented scope: problem-design artifacts, deterministic validation, bilingual briefs, portable reports, bundle manifests and skill distribution. Provider execution, hosted agent orchestration, automatic source verification and equivalent feature breadth to the reference frameworks are not implemented. Host agents provide the reasoning and authorized tool access.
