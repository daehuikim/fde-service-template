# 반도체 현장 참조

## 용어 한 줄

| 묶음 | 용어 |
|---|---|
| 물류·단위 | **로트**: 함께 흐르는 웨이퍼 묶음(보통 25장) · **FOUP**: 웨이퍼 운반 밀폐 용기 · **OHT**: 천장 레일 자동 반송 · **WIP**: 공정 중 재공 · **TAT**: 투입에서 완료까지 걸린 시간 · **Q-time**: 두 공정 사이 허용 대기 상한 |
| 설비·정비 | **레시피**: 설비 공정 조건 묶음 · **챔버**: 실제 공정이 일어나는 방 · **PM/BM**: 예방 정비/고장 정비 · **MTBF/MTTR**: 평균 고장 간격/평균 수리 시간 · **OEE**: 가용률×성능×양품률 |
| 품질·시스템 | **FDC**: 설비 센서로 이상 감지 · **SPC**: 관리도로 공정 변동 감시 · **MES**: 생산 실행 시스템 · **수율**: 양품 비율 · **bin**: 테스트 결과 분류 코드 |

## 예상 과제 유형별 접근

| 유형 | 접근 |
|---|---|
| 설비 정비 일정·인력 배정 + 요청·승인 | CP-SAT 배정 모델(`core/assignment.py`), 검사기, 승인 흐름(`api/domain.py`) |
| 설비 알람·센서 로그 이상 탐지 → 조치 리포트 | 통계 기반 탐지(이동 평균, 관리 한계)는 코드, LLM은 해석과 리포트 초안 |
| 수율 저하 원인 분석 | pandas 집계로 불량 로트의 공통 장비·챔버·시간대 찾기 |
| 로트 투입 순서·병목 스케줄링 | 작업 순서 모델(interval 변수, no_overlap), Q-time 제약, 간트 화면 |
| 물류 경로·부품 재고 | 최단경로, 재고 임계치 규칙 |
| 장비 매뉴얼·조치 이력 검색 | 근거 인용, 작은 평가셋(질문 10개와 기대 근거) |

원인이 불명확하면 `fde-multi-agent-review`로 관점을 나눠 본다(시간이 남을 때만).
