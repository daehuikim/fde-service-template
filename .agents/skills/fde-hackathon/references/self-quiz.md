# 확인 질문 자가 점검

**언제**: 빌드 종료 20분 전. **누가**: 에이전트가 결과물(코드, `docs/`, 테스트 로그)을 읽고 예상 질문 5개를 만든다. 소유자는 **AI 없이 소리 내어** 답한다.

답변 공식: **약점 → 파급 위험 → 검증·개선 방안**. 답에는 계층과 파일명을 넣는다.
예: "권한은 백엔드 `hk/auth.py`의 `authorize()`에서 요청마다 검사한다. 약점은 세션 저장소가 SQLite 단일 파일이라 서버 여러 대로 늘리면 공유가 안 된다는 점이고, 운영에서는 세션 저장소를 분리해야 한다."

고정 질문 6개(여기에 과제 고유 질문을 더해 5개를 고른다):
1. 요청 하나가 어떤 경로로 처리되나?
2. 세션과 권한은 어디서 검사하나?
3. 해가 없을 때 화면에 무엇이 나오나?
4. 예산 초과는 어디서 막나?
5. 두 사람이 동시에 승인하면?
6. 가장 약한 부분은 어디인가?

에이전트 지시문:
> `docs/`와 `git log`, 마지막 테스트 출력을 읽고, 심사자가 물을 법한 질문 5개를 만들어라. 각 질문에 근거 파일명과 "좋은 답의 요소"를 붙이되 답 자체는 쓰지 마라.
